# India Crime Analysis Dashboard – Tableau

## 📊 About the Project

I created this project to explore crime data in India and understand how crime patterns changed over different years and categories.

I cleaned and analyzed the dataset and then built an interactive dashboard in **Tableau** to make the insights easier to understand.

## 🛠️ Tools Used

- Tableau
- Excel / CSV
- Data Analysis

## 🔍 What I Analyzed

- Crime trends over the years
- Different crime categories
- State/region-wise crime data
- Year-wise comparisons

## 🔄 Workflow

```text
Dataset → Data Cleaning → Analysis → Tableau Visualization → Dashboard
```
